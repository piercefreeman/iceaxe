# Fields

Use `Field` to configure a column. It accepts the parameters supported by
[Pydantic Fields](https://docs.pydantic.dev/latest/concepts/fields/#numeric-constraints),
plus database options such as primary keys and foreign keys.

## Postgres Types

Some Postgres types have options that a Python type alone cannot express,
such as whether a timestamp uses Postgres's time-zone-aware type. Pass a configuration
class to `Field(postgres_config=...)` to set these options.
